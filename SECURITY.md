# Security

Please report vulnerabilities privately: the repository's **Security** tab → **Report a vulnerability**. Don't open a
public issue for them. English or Spanish, either is fine.

What counts: anything that lets a file someone else made run code or harm your system through the port. The port
reads files from outside the release:

- disc images, on the first run;
- mods in `data/mods/` and new fields from the field editor (`data/mods/stages/*.json`), which people share;
- memory cards (`saves/*.mcd`) from emulators or other players;
- `native.ini`.

Only the latest release is supported. Crashes with no security impact are welcome as normal bug reports.
